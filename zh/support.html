常见问题解答

如何制作 GIF？

打开应用，点按「转换视频」，从「照片」或「文件」中选择一个视频，裁剪你想要的片段，调整质量设置，然后点按「创建 GIF」。

我的 GIF 看起来模糊，如何提升质量？

导出前进入质量设置。提高分辨率（Pro 用户最高可选原始分辨率）并设置更高的帧率（15 或 20）。请注意，质量越高，文件越大。

如何恢复我的 Pro 购买？

打开应用，进入 Pro 标签页，点按「恢复购买」。请确保使用与原购买相同的 Apple ID 登录。如果恢复无效，请尝试重启应用。

如何取消订阅？

前往 iPhone 或 iPad 的「设置」→ 点按顶部的 Apple ID →「订阅」→ 找到 GIF Maker →「取消订阅」。你在当前计费周期结束前仍可继续使用。

选择视频时应用崩溃，我该怎么办？

请尝试重启应用。确保已在「设置」→ GIF Maker →「照片」中授予照片访问权限。如果问题仍然存在，请将应用更新到最新版本或重启设备。

我可以在 iPad 上使用 GIF Maker 吗？

可以。GIF Maker 支持运行 iOS 16.0 或更高版本的 iPhone 和 iPad。

恢复购买

如果你之前购买过 GIF Maker Pro 并需要恢复（例如重新安装应用或更换设备后）：

  1. 在你的设备上打开 GIF Maker
  2. 进入 Pro 标签页
  3. 点按「恢复购买」
  4. 确保使用与原购买相同的 Apple ID 登录
