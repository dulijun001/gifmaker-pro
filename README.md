# GIF Maker Pro — 官方落地页与全套 SEO 矩阵项目

由 **REA-Cloner Pro** 自动生成的全态 1:1 离线化完整商业官网与 SEO 导流工程。

## 目录结构
- `en/` : 英文版完整官网及 10 篇高权重 SEO 专栏（实况转 GIF、iPhone 转 GIF、无水印 GIF、压缩减小体积等）
- `zh/` : 中文版完整官网与页面支持
- `assets/` : 离线化 CSS、全量 WOFF2 字体、App 原生高清截图与 SVG 标识
- `Dockerfile` & `package.json` : 一键本地预览与全球部署支持

## 本地启动
```bash
# 方式 1: Python
python3 -m http.server 8080

# 方式 2: Node.js
npm start
```
